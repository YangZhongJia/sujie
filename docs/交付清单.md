# 项目说明

ShotBridge 是一款 Windows 局域网截图传输工具。截图电脑通过悬浮球截取当前窗口、显示器、整个屏幕或手动框选区域，在编辑器标注后发送到一个或多个接收电脑。

每台电脑安装同一个程序，首次运行选择「只截图」「只收图」或「同时截图和收图」。接收端默认将图片保存到「图片\\ShotBridge」，并按日期分文件夹。

## 验证

打包后的程序已通过端到端检查：接收服务响应、悬浮球显示和拖动、点击截图、图片传输及 PNG 文件校验。

## 文件

- `src/shotbridge/`：截图端、接收端和局域网传输代码
- `installer/`：Windows 安装包脚本
- `tools/package.ps1`：构建脚本
- `tests/`：自动检查
