# 项目说明

速截 是一款 Windows 局域网截图 / 录屏传输工具。截图电脑通过悬浮球截取当前窗口、显示器、整个屏幕或手动框选区域，在编辑器标注后发送到一个或多个接收电脑；也可以长按悬浮球用四向扇形菜单录屏、贴图或查看最近记录。

每台电脑安装同一个程序，首次运行选择「只截图」「只收图」或「同时截图和收图」。接收端默认将图片保存到「图片\\速截」，并按日期分文件夹。

## 功能一览

| 能力 | 入口 | 说明 |
| --- | --- | --- |
| 截图并标注 | 单击悬浮球 | 画笔/箭头/矩形/圆/文字/马赛克，撤销重做，点「发送」上传 PNG |
| 录屏 | 长按→左滑 / 托盘菜单 / `Ctrl+Alt+R` | 内置 ffmpeg，可选范围、帧率、体积上限，录完自动发送 |
| 贴图对照 | 长按→右滑 | 钉在屏幕最上层，滚轮缩放、拖动、双击关闭，不发送 |
| 最近记录 | 长按→下滑 / 托盘菜单 | 保留最近 200 条，可打开、重新发送、清空 |
| 多接收端 | 设置 → 接收端 | 扫描局域网或手填 IP，每台可设独立密钥 |
| 断线补发 | 自动 | 只为未送达的接收端排队，恢复后补发 |

## 文件

- `src/sujie/`：截图端、接收端、录制、贴图、历史、局域网传输代码
- `assets/bin/ffmpeg.exe`：内置录制组件（打包后位于 `_internal\\ffmpeg\\`）
- `installer/`：Windows 安装包脚本
- `tools/package.ps1`：构建脚本
- `tests/`：自动检查
