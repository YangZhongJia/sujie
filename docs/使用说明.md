# ShotBridge 使用说明

## 安装和模式

在每台 Windows 10/11 64 位电脑上安装同一个程序。首次启动选择本机用途：

- **只截图**：显示悬浮球，截图后发送到配置的接收端。
- **只收图**：在托盘运行 HTTP 接收服务，把收到的图保存到本机。
- **同时截图和收图**：同时运行以上两个角色。

之后可在截图端「设置 → 通用」或接收端托盘菜单里切换模式。安装包开始菜单也有三个模式快捷方式。

## 添加接收端

截图端打开「设置 → 接收端」：

1. 点「扫描局域网设备」并双击一个设备，或手动填写 IP 和端口。
2. 输入该接收端的密钥（没有设置则留空），点「添加 / 更新目标」。
3. 重复添加其他接收端。每台接收端可以使用自己的密钥。
4. 点「保存」测试连接。

截图会发送给列表中的全部接收端。某些接收端暂时离线时，在线端照常收到；未送达的目标会单独排队，恢复连接后补发。

## 截图和编辑

单击悬浮球后会打开编辑器。可使用画笔、箭头、矩形、圆形、文字、马赛克和撤销/重做。点「发送」上传编辑后的 PNG；点「取消」丢弃这张图。

悬浮球右键可切换截图方式：活动窗口、当前显示器、整个屏幕或手动框选区域。

## 接收端设置

接收端默认保存到「图片\\ShotBridge」，按日期分文件夹。托盘菜单可打开或更改目录、查看 IP 和端口、设置共享密钥、切换工作模式和开机自启。

## 网络和安全

接收端默认使用 TCP 8765，局域网发现使用 UDP 8766。安装包为专用网络添加防火墙规则。两台电脑应在同一可信局域网，Windows 网络类型建议设为“专用网络”。

传输使用未加密的 HTTP；共享密钥只用于访问校验，不加密图片内容。不要将接收端端口直接映射到公网。

## 从源码构建

需要 Python 3.10+、PySide6、Pillow、PyInstaller 和 Inno Setup 6：

```powershell
python -m pip install PySide6 Pillow PyInstaller
powershell -NoProfile -ExecutionPolicy Bypass -File tools\package.ps1
```
