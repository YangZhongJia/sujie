# 速截 使用说明

## 安装和模式

在每台 Windows 10/11 64 位电脑上安装同一个程序。首次启动选择本机用途：

- **只截图**：显示悬浮球，截图后发送到配置的接收端。
- **只收图**：在托盘运行 HTTP 接收服务，把收到的图保存到本机。
- **同时截图和收图**：同时运行以上两个角色。

之后可在截图端「设置 → 通用」、接收端托盘菜单，或开始菜单的「更改本机工作模式」里切换。托盘图标不可见时，也可使用开始菜单入口。

## 添加接收端

截图端打开「设置 → 接收端」：

1. 点「扫描局域网设备」并双击一个设备，或手动填写 IP 和端口。
2. 输入该接收端的密钥（没有设置则留空），点「添加目标」。
3. 重复添加其他接收端。每台接收端可以使用自己的密钥。
4. 点「保存」测试连接。

截图会发送给列表中的全部接收端。某些接收端暂时离线时，在线端照常收到；未送达的目标会单独排队，恢复连接后补发。

## 截图和编辑

单击悬浮球后会打开编辑器。可使用画笔、箭头、矩形、圆形、文字、马赛克和撤销/重做。点「发送」上传编辑后的 PNG；点「取消」丢弃这张图。

悬浮球右键可切换截图方式：活动窗口、当前显示器、整个屏幕或手动框选区域。

## 长按扇形菜单

按住悬浮球约半秒不放，会弹出四个扇形入口；保持按住往某个方向滑出去再松手即可执行：

| 方向 | 动作 | 说明 |
| --- | --- | --- |
| 向上 | 截图 | 等同于单击悬浮球 |
| 向左 | 录屏 | 开始录制，再单击小球停止并按配置发送 |
| 向右 | 贴图 | 把当前截图钉在屏幕上对照，不发送 |
| 向下 | 最近记录 | 打开最近截图/录屏列表 |
说明：
- 小球默认停在屏幕右上（距边约 140 像素），给扇形留出空间；拖到屏幕边缘也没关系，扇形会自动缩小，四个扇区始终完整可见。
- 展开扇形后如果决定不做，把指针留在中心圆里松手即可取消，不会触发截图。
- 长按阈值、扇形半径、是否显示「预留」槽位都可以在「设置 → 通用」里调整。

设置 → 通用里可以关闭扇形菜单、调整长按时间和扇形半径。

## 录屏

设置 → 录制里选择录制范围（当前显示器 / 整个屏幕 / 当前活动窗口 / 手动框选）、帧率（默认 30）、单文件上限（默认 2048 MB）和保存目录。录屏使用内置 ffmpeg，不需要另外安装。

录制中悬浮球会变成红色并显示计时；单击小球或按 `Ctrl+Alt+R` 停止。停止后按设置自动发送给接收端，也可以在历史记录里重新发送。

默认只录画面不录声音。要录麦克风，需要在设置里选择麦克风设备（本机没有音频采集设备时会提示）。

## 贴图

截图后用「贴图」把图片钉在屏幕最上层，常用于对照抄写或比对两处界面。滚轮缩放，拖动移位，双击或按 Esc 关闭，右键可复制图片或另存为。设置里可以限制最多同时贴几张、以及抓屏时是否自动隐藏贴图。

## 最近记录

托盘菜单「最近记录…」或扇形菜单下滑可打开历史，保留最近 200 条（可调）。可以打开原图/视频、打开所在文件夹、重新发送给接收端或清空。发送成功的图片会留一份副本在 `%LOCALAPPDATA%\速截\sent`。

## 接收端设置

接收端默认保存到「图片\\速截」，按日期分文件夹。托盘菜单可打开或更改目录、查看 IP 和端口、设置共享密钥、切换工作模式和开机自启。收到的最大单文件默认 2048 MB，可在接收端设置里调整。

## 网络和安全

接收端默认使用 TCP 8765，局域网发现使用 UDP 8766。安装包为专用网络添加防火墙规则。两台电脑应在同一可信局域网，Windows 网络类型建议设为“专用网络”。

传输使用未加密的 HTTP；共享密钥只用于访问校验，不加密图片内容。不要将接收端端口直接映射到公网。

## 从源码构建

需要 Python 3.10+、PySide6、Pillow、PyInstaller 和 Inno Setup 6：

```powershell
python -m pip install PySide6 Pillow PyInstaller
powershell -NoProfile -ExecutionPolicy Bypass -File tools\package.ps1
```
