# ShotBridge 使用说明

## 两台电脑安装

在两台 Windows 10/11 64 位电脑上运行 `ShotBridge-Setup-1.0.0.exe` 安装。

### 收图电脑

从开始菜单打开「接收端（托盘服务）」。接收端会在后台运行，截图默认存入「图片\\ShotBridge」，并按日期分文件夹。

右键任务栏托盘里的 ShotBridge 图标可以：

- 打开截图文件夹
- 查看本机 IP 和端口（默认 8765）
- 更改保存目录
- 设置共享密钥（可留空）
- 开机自启或退出

### 截图电脑

打开「截图端（悬浮球）」。首次启动会显示设置窗口：

1. 点「扫描局域网设备」，双击收图电脑；扫描不到时手动填写其 IP。
2. 如收图端设置了共享密钥，填写相同密钥。
3. 点「保存」。程序会测试连接并显示结果。

之后点悬浮球即可截图并发送。按住拖动悬浮球可移动它；右键可选择截图方式、打开设置或退出。

## 截图方式

- 当前活动窗口
- 鼠标所在的显示器
- 所有显示器
- 手动框选区域

截图使用 PNG 格式。发送失败的截图会暂存在本机，网络恢复后自动补发。

## 无法连接

确认两台电脑连在同一个局域网，收图电脑的接收端正在运行，Windows 网络类型设为「专用网络」。安装包会添加 TCP 8765 和 UDP 8766 防火墙规则；如使用自定义端口，请在两台电脑的设置中保持一致并手动放行。

## 从源码运行

```powershell
python src\\shotbridge_client.py
python src\\shotbridge_receiver.py
```

构建安装包需要 Python 3.10+、PySide6、Pillow、PyInstaller 和 Inno Setup 6：

```powershell
python -m pip install PySide6 Pillow PyInstaller
powershell -NoProfile -ExecutionPolicy Bypass -File tools\\package.ps1
```
